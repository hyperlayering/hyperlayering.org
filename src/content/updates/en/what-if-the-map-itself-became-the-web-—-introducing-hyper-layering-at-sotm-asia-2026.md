On September 7, 2026, I gave a keynote about **Hyper Layering** at **[State of the Map Asia 2026](https://stateofthemap.asia/)** in Osaka. The title was **“What if the Map itself became the Web?”**

In the talk, I looked back at the development of Hyper Layering since the 1990s, introduced its current implementation using **Layers as Web Apps (LaWA)**, and discussed where HLA might go next.

The basic idea behind Hyper Layering is to combine independent Web resources as map layers in the browser, while allowing each resource to retain its independence. Rather than collecting information into a single system for integration, each provider can continue to operate its own information and services independently, while users combine them as needed.

The keynote included demonstrations of real-world systems and applications, covering disaster information, thematic maps, the overlay of maps using different projections, QuadTree Composite Tiling, and client-side spatial operations. I also touched on the next stage of Hyper Layering, HLA 3.0, and the possibility of using the Web itself as material for creating maps.

## Why talk about Hyper Layering at SotM Asia?

For us, presenting Hyper Layering at SotM Asia had a particular significance.

OpenStreetMap has made maps open by enabling anyone to use, edit, and share them. What more could we do with this open map?

Hyper Layering aims to make it possible to combine not only map data, but also the diverse Web resources that make up a map, while allowing each to remain independent. It seeks to extend the open world of maps that OpenStreetMap has helped create to the Web as a whole. To do this, maps should not have to be confined within a single system. Instead, independent information and services available on the Web should be usable directly as building blocks for maps.

In this keynote, I shared this idea with the OpenStreetMap community through the question, **“What if the Map itself became the Web?”** It was also a valuable opportunity for us to reflect on the future direction of Hyper Layering.
